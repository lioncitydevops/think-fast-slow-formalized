1. Executive Summary & Theoretical Grounding

This report presents the formal system architecture and operational transition mechanics for a dual-process cognitive computing system modeled after Daniel Kahneman’s behavioral psychology paradigm (Thinking, Fast and Slow, 2011) and its mathematical formalization by Yan Zhang & TzeHoung Lee (National University of Singapore, ASSE 2026).

Modern AI engineering suffers from an expensive dichotomy: lightweight classification models are fast but prone to associative biases and hallucinations, while heavy reasoning models (such as deep chain-of-thought LLMs) generate immense token volume and latency, often succumbing to inverse scaling or rationalization of incorrect premises when applied indiscriminately. Our implemented architecture bridges this divide by orchestrating TypeSafe Jev (System 1: sub-second calibrated judgment) and Qwen3-8B (System 2: local token-budgeted deliberation) through a metacognitive controller governed by the Expected Value of Control (EVC).

2. Complete End-to-End System Architecture

The system is divided into four cleanly decoupled yet tightly coordinated stages: (1) System 1 Associative Evaluation, (2) Metacognitive EVC Controller & Calibration Auditor, (3) System 2 Deliberative Engine & Interaction Patterns (P1–P5), and (4) Autonomous Safety Fallbacks.

3. Comprehensive Breakdown of Switching Conditions

The core contribution of the Zhang & Lee (2026) paper is replacing heuristic rules with mathematically certified boundaries. Transitions are strictly bi-directional: System 1 escalates to System 2, System 2 de-escalates or reverts back to System 1, and intractable tasks drop into autonomous fallbacks.

PART I: Conditions Where System 1 Switches to System 2 (Escalation / Deliberation)

System 1 forfeits its fast autonomous execution and awakens the reasoning engine under five specific mathematical conditions:

Condition 1.1: Act-Band Confidence Threshold Violation (Proposition 5.3 & Remark 1)

Mathematical Trigger:

c = max_{k in A} p_k < tau*

Formal Grounding: Under calibration, the expected error of System 1 on queries with confidence at least τ satisfies: P(a1 != y | c >= tau) <= 1 - tau. When the top probability drops below the certified threshold tau*, this error guarantee fails. tau* is certified using Clopper-Pearson exact binomial inversion at confidence level 1 - delta (typically 95%):

tau* = min { tau in T : Beta_ppf(1 - delta, k_tau + 1, n_tau - k_tau) <= epsilon }

Operational Impact: For queries with c < tau*, fast autonomy is revoked, and the metacognitive controller routes the query into System 2 deliberation.

Condition 1.2: Positive Expected Value of Control (EVC Surplus) (Proposition 5.6 & 5.7)

Mathematical Trigger:

s(c) = [(1 - c) - r * c] * (1 - [2(1 - c)]^gamma) > lambda * beta

Formal Grounding: Deliberation requires spending costly reasoning tokens. The Expected Value of Control (EVC) objective is: V(B, c) = s(c) * h(B) - lambda * B, where h(B) is the token return curve, lambda is the price of thought per token, and beta is the token scaling scale. Under saturating returns h(B) = 1 - exp(-B / beta), the derivative with respect to budget yields:

B*(c) = beta * ln( s(c) / (lambda * beta) )

Deliberation is awakened if and only if s(c) > lambda * beta (yielding B*(c) > 0). The upper boundary above which System 1 never wakes System 2 is defined in closed form: c_upper = (1 - lambda * beta) / (1 + r).

Condition 1.3: Conflict Detection via Fast Disagreement Probe (Pattern P3, Section 6)

Mathematical Trigger:

a0 != a1 (where a0 = Qwen(x, B=0), a1 = Jev(x))

Formal Grounding: Associative intuition often suffers from WYSIATI (What You See Is All There Is) and deceptive cognitive lures (e.g., Cognitive Reflection Test lures, trick wording in requirements, or subtle security regressions in pull requests) where System 1 produces an error with deceptive high confidence (c >= tau). Pattern P3 runs a zero-budget probe a0 = Qwen(x, 0) concurrently. Even if c >= tau, probe discordance a0 != a1 overrides the act band and triggers effortful deliberation (B > 0), achieving an empirical AUROC of 0.82 in predicting deliberation payoff.

Condition 1.4: Wald Sequential Probability Ratio Test (SPRT) Drift Alarm (Section 7.1)

Mathematical Trigger:

S_n = sum_{i=1}^n ln( P(E_i | H1) / P(E_i | H0) ) >= ln( (1 - beta_sp) / alpha_sp )

Formal Grounding: The controller continuously audits a random sample of act-band judgments against true ground truth. Under null hypothesis H0: error <= epsilon versus alternative H1: error >= epsilon + delta_sp, if the cumulative log-likelihood ratio breaches the upper boundary A, a distribution drift alarm is sounded. All autonomous acting is suspended, and 100% of incoming queries are escalated to System 2 until recalibration.

Condition 1.5: High-Stakes Asymmetric Penalty Override (Proposition 5.9)

Mathematical Trigger:

s(c) * L_{false_positive} >> lambda * beta

Formal Grounding: In high-consequence enterprise applications (e.g., automated database migrations, patient medication routing), the cost of an intuitive misclassification dwarfs token inference costs. The effective price of thought collapses (lambda -> 0), expanding the deliberation window and forcing escalation even on queries with c = 0.94.

PART II: Conditions Where System 2 Switches Back to System 1 (De-escalation / Verifier Reversion / Fast Act)

Deliberation is expensive and susceptible to fluent overthinking. The system enforces four strict conditions where control de-escalates, suppresses System 2, or reverts System 2’s overrides back to System 1:

Condition 2.1: Law of Least Effort Suppression (Act Band)

Mathematical Trigger:

c >= tau* AND s(c) <= lambda * beta

Formal Grounding: When Jev’s confidence meets the certified safety threshold and the EVC surplus is zero or negative, System 2 is completely suppressed. The reasoning model is never invoked (B = 0 tokens, latency < 250ms, token cost = $0.00). System 1’s answer a1 is released immediately with certified bounded risk.

Condition 2.2: Disagreement Probe Concordance under Low Stakes (Pattern P3)

Mathematical Trigger:

a0 == a1 AND (B*(c, task) < 256 OR c >= tau*)

Formal Grounding: In Pattern P3, when the zero-token probe agrees with System 1’s intuition (a0 == a1) and the marginal task-conditioned budget is small, thinking is deemed redundant. The controller aborts deeper deliberation and returns System 1’s action a1, saving 100% of deliberative tokens.

Condition 2.3: Stage-3 Rationalization Reversion (Pattern P4: Jev as Verifier, Table 11 H6)

Mathematical Trigger:

b != a1 AND Jev(Passage: x, Reasoning: trace_b) = "unsupported" with c_verifier >= 0.75 ==> b <- a1

Formal Grounding: A critical pathology identified in Section 6 is that when an LLM deliberates on already-correct intuitive judgments, it frequently rationalizes incorrect conclusions through fluent, deceptive reasoning chains (Stage-3 rationalization). Pattern P4 addresses this by using System 1 as an independent evaluator: when Qwen produces an override b != a1, Jev audits the generated reasoning trace. If Jev evaluates the override as factual hallucination or unsupported reasoning with confidence ≥ 0.75, the controller reverts the decision back to System 1's initial answer a1. Our empirical evaluation proves this cuts harmful overrides by 38.5% while preserving >85% of beneficial overrides.

Condition 2.4: Decision Hygiene Reconciliation (Pattern P5, Proposition 5.4 & Corollary 5.5)

Mathematical Trigger:

Qwen_Turn2(x, reasoning_trace, a1, c) fails to find verifiable flaw ==> b <- a1

Formal Grounding: Providing System 1’s answer upfront in System 2’s prompt causes severe cognitive anchoring: G^{inf} = (1 - alpha) * G^{blind}, where alpha is the pure anchoring share. Under Pattern P5 (Blind-then-Reconcile), System 2 reasons blind first (b). Only in a concise Turn 2 is it shown (a1, c) with strict instructions to override only if it identifies a concrete, falsifiable error in Jev’s premise. If no concrete defect is identified, the system harmonizes and defers back to System 1.

PART III: Conditions Where the Controller Switches to Autonomous Fallbacks

When tasks are hopeless or intrinsically ambiguous, neither System 1 nor System 2 can produce a reliable answer. The controller switches to autonomous fallbacks without human intervention:

Condition 3.1: Give-Up Band Ambiguity Exhaustion (Proposition 5.6 & Table 6)

Mathematical Trigger:

c <= tau_giveup (where s(c) <= lambda * beta) OR B*(c) == 0 OR post_error(c, B) > epsilon

Formal Grounding: As confidence approaches random chance (c -> 0.50 for binary classification), the ambiguity penalty 1 - d^gamma collapses toward zero. Deliberation returns diminish sharply, and LLM reasoning produces inverse scaling (hallucination). The controller recognizes the task as intractable and halts execution.

Condition 3.2: Calibrated Bayes Action Fallback (Proposition 5.9)

Mathematical Trigger:

a*(p) = argmin_{a in A U {hold}} sum_k p_k * L(a, k)

Formal Grounding: When in the give-up band, instead of forcing a speculative prediction, the system calculates the Bayes-optimal action under the specified loss matrix L. If the expected loss of misclassification exceeds the holding penalty c_hold, the system autonomously emits the safe quarantine action "hold".

Condition 3.3: Conformal Prediction Set Fallback (Proposition 5.10)

Mathematical Trigger:

C(x) = { k in A : 1 - p_k(x) <= q_hat } guaranteeing P( y in C(x) ) >= 1 - alpha

Formal Grounding: If an action cannot be narrowed to a single candidate, the controller outputs a certified prediction set C(x) calibrated via conformal prediction quantile q_hat, bounding marginal coverage error to strictly less than alpha (e.g. 5%).

7. Conclusion & Architectural Invariants

The dual-process cognitive controller satisfies three fundamental architectural invariants:

  1. Conservation of Thought: Deliberative reasoning tokens are strictly non-negative in cost (lambda > 0) and are deployed if and only if the expected value of control surplus s(c) > lambda * beta.
  2. Safety Parity: In the act band, empirical error is bounded by epsilon with confidence 1 - delta via Clopper-Pearson exact inversion; in the give-up band, error is bounded via conformal prediction sets C(x).
  3. Bidirectional Resilience: System 2 corrects intuitive System 1 biases when prompted blindly, while System 1 audits and reverts System 2 hallucinations when reasoning overreaches.
